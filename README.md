# PyME
Roloff Matek

### Deutsch ###

Vorauslegungen und Festigkeitsberechnungen zu Maschinenelementen gemäss Lehrmittel.
Aus den Kapiteln von  Roloff Matek sind die folgenden Berechnungen anwendbar:
- Schraubenverbindungen
- Federn
- Rollen- und Kugellager
- Gleitlager
- Wellen und Achsen
- Wellen- und Nabenverbindungen
